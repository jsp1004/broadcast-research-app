# 방송 리서치 도우미

방송 프로그램 기획자/PD가 장르·출연자를 입력하면, 웹(뉴스·커뮤니티·유튜브 댓글·SNS)에서 유사 프로그램 사례와 출연자 평판을 AI가 자동으로 수집해 정리해주는 리서치 도구입니다.

**배포 주소**: https://my-app-eight-azure-32.vercel.app (로그인 없이 누구나 접근 가능)

## 핵심 기능

### 1) 유사 프로그램 리서치
장르/키워드를 입력하면 국내외 유사 방송 프로그램을 포맷·화제성·성공 여부·출처와 함께 카드로 정리합니다.
- 결과 5~10개, 국내·해외 각 1개 이상 포함
- 프로그램마다 출처 링크 표기, 신뢰 가능한 출처 우선
- 확인 안 되는 정보는 "정보 없음"으로 별도 표시

### 2) 예상 출연자 리서치
출연자명을 입력하면 이전 출연작·화제성·호감도(%)를 카드로 정리합니다.
- 최근 36개월 이내 자료 우선, 긍정/부정 언급 비율 수치 제시
- 서로 다른 출처 3곳 이상 교차 확인
- 동명이인 발견 시 임의로 특정하지 않고 사용자가 직접 선택

자세한 기획 배경과 규칙은 [`PRD.md`](PRD.md), 구현 작업 목록은 [`PLAN.md`](PLAN.md), 화면·데이터·기술 설계는 [`DESIGN.md`](DESIGN.md)를 참고하세요.

## 기술 스택

- **Next.js** (App Router) — 프론트엔드와 API를 한 프로젝트에서 처리
- **Supabase** — 검색 결과 저장용 데이터베이스
- **OpenAI API** — 웹 검색 기반 리서치 결과 생성
- **YouTube Data API** — 유튜브 댓글·조회수 데이터로 화제성·호감도 보강
- **Tailwind CSS · shadcn/ui** — UI
- **Vercel** — 배포

## 로컬 실행

```bash
npm install
npm run dev
```

`http://localhost:3000`에서 확인할 수 있습니다.

### 환경 변수

루트에 `.env` 파일을 만들고 아래 값을 채워야 합니다(저장소에는 커밋되지 않습니다).

```
OPENAI_API_KEY=
SUPABASE_URL=
SUPABASE_SERVICE_ROLE_KEY=
YOUTUBE_API_KEY=
```

Supabase 프로젝트에는 `supabase/migrations`의 마이그레이션을 적용해 `research_results` 테이블을 먼저 만들어야 합니다.
